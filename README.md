# 🚗 Car Rental System in C++

A console-based **Car Rental Management System** developed using **C++** that simulates the basic operations of a real-world vehicle rental service. This project demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts, data management using vectors, and menu-driven application development.

## 📌 Features

* Customer Registration
* View Registered Customers
* View Available Cars
* Rent a Car
* Return a Car
* Rental Record Management
* Add New Cars (Admin)
* Delete Cars (Admin)
* Input Validation for Menu Options
* Preloaded Car Inventory

## 🛠 Technologies Used

* C++
* Object-Oriented Programming (OOP)
* STL Vector
* Classes and Objects
* Menu-Driven Interface

## 🏗 Project Structure

### Car Class

Stores vehicle information including:

* Car ID
* Brand
* Model
* Price Per Day
* Availability Status

### Customer Class

Manages customer details:

* Customer ID
* Name
* Phone Number
* Address
* Driving License Number

### RentRecord Class

Maintains rental transaction records:

* Customer ID
* Car ID
* Rental Duration
* Total Bill
* Return Status

## ⚙️ How It Works

1. Register a customer.
2. View available cars from the inventory.
3. Rent a car by providing the Customer ID and Car ID.
4. The system calculates the rental bill automatically based on the number of rental days.
5. Return the rented car and update its availability status.
6. View complete rental records at any time.
